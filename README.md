# 🍿 Snack Machine

A simple snack vending machine built with Java to practice object-oriented programming.

The program runs in the console and allows users to manage snacks, add products to a cart, calculate totals, and process payments.

## Features

- 📦 View and add snacks to the inventory
- 🔎 Find products by ID
- 🛒 Add snacks to the cart
- 🧾 Display the purchase total
- 💵 Process payments and calculate change

## Project Structure

```text
src/
├── Snack.java 

```

- `Snack` — Represents a snack and its properties.
- `Snacks` — Manages the inventory.
- `MaquinaSnacks` — Handles the menu, shopping cart, and checkout.

## Requirements

- Java JDK 17 or later

## Running the Project

Compile the source files:

```bash
javac -d out src/*.java
```

Run the application:

```bash
java -cp out MaquinaSnacks
```
